# 🖥️ Enterprise IT Support Lab (Active Directory)

### 🎯 Project Overview
A comprehensive simulation of an enterprise network environment. This project demonstrates the design, deployment, and management of a Windows Server Active Directory domain, replicating real-world IT support tasks.

### 🛠️ Technologies Used
* **Hypervisor:** VirtualBox 7.0
* **Server OS:** Windows Server 2022 (Domain Controller)
* **Client OS:** Windows 10 Pro (Domain Joined)
* **Network:** NAT Network (10.0.2.0/24) with Custom DNS
* **Tools:** PowerShell, Remote Desktop (RDP), Active Directory Users & Computers (ADUC)

### 📂 Repository Structure
* `documentation/` - Detailed ticket logs and troubleshooting steps.
* `screenshots/` - Visual proof of configurations.
* `scripts/` - PowerShell scripts for automation.

### 🚀 Key Skills Demonstrated
* Active Directory Domain Services (AD DS) Deployment
* User & Group Management (IAM)
* Network Troubleshooting (DNS, DHCP, TCP/IP)
* Security Policy Implementation (Password policies)
* Remote Support Administration (RDP)
